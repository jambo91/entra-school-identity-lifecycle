# Screenshot Evidence

This folder contains sanitised evidence from the Microsoft Entra school identity lifecycle project.

The evidence demonstrates:

- Dynamic student and teacher group membership
- Group-based Microsoft Entra ID P2 licensing
- Teacher departmental transfer
- Automatic access changes
- Successful sign-in before offboarding
- Account disabling
- Session revocation
- Blocked sign-in after offboarding
- Microsoft Entra audit and sign-in logs

All identities shown are fictional.

Passwords, tenant information, full usernames, IP addresses, object identifiers and other sensitive information have been removed or hidden.
