# Microsoft Entra School Identity Lifecycle Management

## Project Status

🟡 In Progress

## Project Overview

This home-lab project demonstrates how Microsoft Entra ID can be used to manage the identity lifecycle of fictional students and teachers in a school environment.

The project will demonstrate user creation, profile configuration, group membership, access assignment, testing, monitoring and secure account offboarding.

## Business Scenario

Northstar Academy needs a secure and organised method for managing student and teacher identities.

The school must ensure that:

- New students and teachers receive the correct accounts.
- Users are placed into the correct groups.
- Access is provided according to the user's role and department.
- Changes to user information update access appropriately.
- Accounts are disabled securely when users leave.
- Administrative activities can be reviewed through audit logs.

## Project Objectives

- Create fictional student and teacher accounts
- Configure important user attributes
- Create appropriate security groups
- Configure dynamic group membership
- Assign access and licences
- Test the student and teacher experiences
- Simulate a user changing department or course
- Securely offboard a user
- Review audit logs
- Document the implementation and results

## Security Notice

This project uses fictional identities in a controlled home-lab environment.

No passwords, access tokens, private keys or confidential information will be published.
